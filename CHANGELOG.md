# Changelog

All notable changes to hardluau.

## [0.1.0] - 2026-09-25

### Added

- Initial corpus: syntax, luau-specific, semantic-traps, and
  formatting-extremes categories.
- `metadata/index.json` and `metadata/schema.json`.
- `generators/` procedural case generators.
- `tests/validate_syntax.py` and `tests/run_against_tools.py`.
- CI workflow (`.github/workflows/validate.yml`) and issue template.
